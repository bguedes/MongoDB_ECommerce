# MongoDB_ECommerce

== Introduction

MongoDB_ECommerce is a sample e-commerce application designed to showcase the flexibility of MongoDB's document-oriented data model. 
It demonstrates how product, order, and user data can be represented using rich, nested documents and arrays, enabling easy adaptation to evolving business requirements. 

The project highlights MongoDB's ability to store diverse product attributes—such as varying specifications for electronics or apparel—without rigid schema constraints. 

This flexibility allows for rapid development, efficient querying, and seamless scaling as new features or data types are introduced. 

By leveraging MongoDB's dynamic schema, the application supports complex e-commerce scenarios, including product variants, reviews, and order management, 
all within a unified and agile data structure.

== Pre-requisites

. A https://account.mongodb.com/account/register[MongoDB Atlas free] account.
. A modern browser - Google Chrome (IE, Firefox, Safari not supported).
. Wifi Internet connection.
. Git installed.
. Node.js and npm installed.
. https://www.mongodb.com/try/download/compass[Compass] installed.

== Step 1: Intall the local application

Follow this steps:

[,console]
----
git clone https://github.com/bguedes/MongoDB_ECommerce.git

cd backend
npm install

cd ../frontend
npm install

cd ..
npm run dev
----
